## מקור אמת
הקובץ המחייב ביותר בריפו הוא `SSOT.md`.

Teacher Hub כולל את כלי המורה מתוך Moodle, LTI, נתוני Moodle אמיתיים, Render, Supabase, import, תלמידים, ציונים, לוגים ודוחות.

`https://www-tijc.onrender.com`
